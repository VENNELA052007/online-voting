# Online Voting System

A simple SDC project made with HTML, CSS and JavaScript.

## Modules

- Admin: login, add/delete candidates, view voters, start/stop election and view results
- User: signup, login, view candidates and cast one vote

## Run

Open `index.html` in a web browser.

Admin login:

- Email: `admin@voting.com`
- Password: `admin123`

The project stores users, candidates, election status and votes in the browser's Local Storage.
