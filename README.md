# Online Voting System

This is a basic student election project made with HTML, CSS and JavaScript.

## Modules

- Admin: manages candidates, election status, voters and results.
- Voter: signs up, logs in, views candidates and votes once.

## Run

Open `index.html` in a web browser. User and election data are saved in Local Storage.
